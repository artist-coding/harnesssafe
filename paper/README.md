# HarnessSafe 论文

**HarnessSafe: Evaluating Safety Across Persistent Carriers in Agent Harnesses**

Xiao Zhang · Yusheng Wang · Yuhao Fei · Dongyuan Li · Zian Liang · Liuyu Xiang · Hongxun Gu · Zhaofeng He

[arXiv 论文](https://arxiv.org/abs/2608.06984) · [论文 PDF](https://arxiv.org/pdf/2608.06984) · [项目网站](https://artist-coding.github.io/) · [DOI](https://doi.org/10.48550/arXiv.2608.06984)

论文于 2026 年 8 月 7 日发布于 arXiv。阅读论文及其附录请使用上方公开版本入口。

论文围绕 agent harness 中的持久风险展开，以 Persistent-Risk Lifecycle 描述从攻击入口到后续触发与违规的路径，在七类机制的 328 个案例上开展分阶段评估。论文中的历史实验结果对应原文配置；当前仓库的新实验应单独报告，执行与评分边界见 [适配器状态](../docs/adapters.md)。
